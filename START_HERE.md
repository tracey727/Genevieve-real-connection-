# START HERE — Tracey's deployment steps

You do **not** need to understand the code.

## Put this on GitHub

1. Download and unzip `genevieve-real-connection-trial.zip`.
2. Open GitHub in your browser and sign in.
3. Create a new repository.
4. Name it `genevieve-real-connection-trial`.
5. Choose **Private** while this is your personal trial.
6. Create the repository.
7. Choose **Add file → Upload files**.
8. Upload the files **inside** the unzipped `genevieve-real-connection-trial` folder. The file `index.html` must be at the top level of the GitHub repository, not inside another nested folder.
9. Commit the files.

## Put the GitHub project on Vercel

1. Open Vercel and sign in with the account connected to your GitHub.
2. Choose **Add New → Project**.
3. Find `genevieve-real-connection-trial` and choose **Import**.
4. Leave the project as a plain/static project. You do not need to enter environment variables for V1.
5. Choose **Deploy**.
6. When Vercel finishes, open the web address it gives you.

## What to test first

1. Open **Today** and choose how much connection you want today.
2. Add one pretend person in **People** first, just to test the buttons.
3. Use **Reflect** and make sure the answers save.
4. Open **Deeper?** and test the green/yellow/red progression check.
5. Add something to **Life List**.
6. Close the website and reopen it. Your trial data should still be there on the same browser/device.
7. Go to **Privacy → Export data** and confirm a JSON backup downloads.

## Important V1 limitation

Your personal data is saved to the browser on that device. It does **not** automatically sync between your iPhone and laptop. Do not delete browser/site data unless you have exported a backup first.

When the personal trial proves what works, V2 can add secure accounts and synchronisation. A public friend-matching system should not be switched on until identity, moderation, privacy, consent, reporting and location-safety controls are built and tested.
